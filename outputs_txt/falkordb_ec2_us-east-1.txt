Notes: 
For the setup had problems with bolt as the documentation command provided to run falkordb + bolt wasnt working locally and in my ec2 instance.
I then decided to use redis port and falkor library instead. Since it still used cypher, I was still able to use my codes in here, I just had to adjust the driver and set it to Falkor.

On initial setup was experiencing timeouts in redis resulting in failed runs, especially for aggregations. 
I initially thought this was a memory problem due to 256 mb resource cap, I inspected the run and noticed the memory not exceeding 256
I after reading the error logs I found out it was a redis proble, the runtime timeout was set to 1000 ms which caused the runtimes of some queries to exceede and fail the test. 
I then modified the docker compose to set the timeout to 30000 ms (30 seconds), to make sure every tests run. 


Also tested the free tier cloud db for falkordb hosted on us-east-1 which had similar results to this setup (view at falkordb_cloud)
